# Dating Assistant Telegram Bot

Telegram bot designed to help users improve their online dating experience with AI-powered assistance.

## Features

- Dating profile generation
- Tinder bio suggestions
- Opening message creation
- Conversation practice
- AI-powered dating advice
- Personalized recommendations

## Technologies

- Python
- python-telegram-bot
- OpenAI API
- PostgreSQL

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python bot.py
```
